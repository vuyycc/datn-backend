# 📦 Node.js Backend API

A RESTful API built with Node.js, Express, Sequelize, and MySQL. Supports user authentication (JWT), file upload (Multer), CSV processing, and more.

---

## 🚀 Features

- User authentication with **JWT**
- Password hashing with **bcrypt**
- Database ORM with **Sequelize** and **MySQL**
- File upload with **Multer**
- CSV parsing and conversion with **csv** and **csvtojson**
- Environment-based configuration using **dotenv**
- CORS support for frontend-backend integration

---

## 🧰 Tech Stack

- Node.js
- Express.js
- MySQL / Sequelize
- JWT (jsonwebtoken)
- bcrypt
- multer
- csv, csvtojson
- axios
- dotenv
- nodemon
